# FP Flow — klinische hoofdstukbaas

Het hoofdstukscherm toont nu een visuele **hoofdstukbaas / klinische mijlpaal** met drie uitsluitend afgeleide statussen: achter de rug, te beoordelen, vergrendeld.

- Vraagt nooit extra oefeningen voor XP of gear.
- Fasevrijgave blijft uitsluitend bij de behandelend therapeut via bestaande criteria; geen knop of API om vanuit de game te promoveren.
- Laat de bestaande patiëntgerichte fase-doelen zien, maar geeft geen exacte private klinische testresultaten vrij.
- Een eerdere fase wordt niet als genezen of geslaagd voor alle criteria gepresenteerd.

Dit is een eerste game-UI-koppeling en **geen** automatisch geëvalueerde klinische test. Latere externe fase-checkpoints vereisen expliciet gevalideerde meetdata, beveiliging en zorginhoudelijke review.
