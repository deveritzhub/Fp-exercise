# Klinische reviewlijst

Gegenereerd op 2026-10-23 met `npm run db:review-report` uit de lokale database (120 oefeningen, 96 nog niet klinisch goedgekeurd).
Dit is een signaleringslijst: niets hieronder is automatisch gecorrigeerd en geen enkel punt is een klinisch oordeel.

- **Barbell bench press** — nu: Schouder; doelspieren: borst, triceps, voorste schouder
- **Barbell row** — nu: Schouder; doelspieren: rug, biceps
- **Chest-supported row** — nu: Schouder; doelspieren: midden rug
- **Dumbbell curl** — nu: Schouder; doelspieren: biceps
- **Face pull** — nu: Schouder; doelspieren: achterste schouder, bovenrug
- **Incline dumbbell press** — nu: Schouder; doelspieren: bovenste borst, voorste schouder
- **Lat pulldown** — nu: Schouder; doelspieren: brede rugspier
- **Overhead press** — nu: Schouder; doelspieren: schouders, triceps
- **Pull-up** — nu: Schouder; doelspieren: brede rugspier, biceps
